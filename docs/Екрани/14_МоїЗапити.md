# 14. Мої запити

## Призначення

Екран відображає всі запити, створені користувачем, незалежно від їхнього статусу. Дозволяє швидко контролювати процес виконання, відкривати картку запиту, редагувати або скасовувати його.

---

## Мета

Надати користувачу єдине місце для керування власними запитами.

---

## Основні елементи

### Верхня панель

- Назва «Мої запити»
- Пошук
- Фільтр

### Вкладки

- Усі
- Активні
- Виконуються
- Виконані
- Скасовані

### Картка запиту

Містить:

- Назву
- Категорію
- Статус
- Дату створення
- Кількість відгуків
- Виконавця (якщо призначений)

---

## Дії користувача

Користувач може:

- Відкрити картку запиту
- Відредагувати запит
- Скасувати запит
- Позначити як виконаний
- Видалити завершений запит

---

## Переходи

← Головна

→ Картка запиту

→ Чат

→ Профіль виконавця

---

## API

GET /requests/my

DELETE /requests/{id}

## Можливі помилки

- Недостатньо прав

- Розширені фільтри
